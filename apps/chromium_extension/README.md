# Subconscious Chromium extension

A Manifest V3 extension whose UI is the Flutter web build of `apps/unified_app`, embedded in the popup (400x560)
and the side panel. Only a thin JavaScript **host** remains here, for what Flutter web cannot do: `chrome.*` APIs
and the browser/WebMCP tools. Pairing, sign-in, chat, devices and settings are all Dart now.

## Architecture

```
popup.html / sidepanel.html   GENERATED by scripts/build_extension.ps1 (git-tracked output, do not edit)
  <base href="app/">
  /host.js          classic loader -> import('./tools/host_tools.js'); sets globalThis.subconsciousExtension
                    and globalThis.subconsciousExtensionReady (Promise)
  /mode-popup.js    window.__SUBCONSCIOUS_EXTENSION__ = {mode:'popup'}   (mode-panel.js for the side panel)
  /boot.js          awaits subconsciousExtensionReady, then injects app/flutter_bootstrap.js
app/                Flutter web build (git-ignored build artifact)
tools/              browser + WebMCP tool implementations, redaction (see tools/README.md)
```

No inline scripts (MV3 CSP). CanvasKit, fonts and `main.dart.js` are bundled; there is no service worker.

## Host API (`globalThis.subconsciousExtension`)

All values cross the boundary as JSON strings or primitives (contract: `.agents/tasks/extension-tools-pairing/contracts.md` section 5).

| Member | Notes |
| --- | --- |
| `version`, `mode`, `extensionVersion`, `extensionOrigin` | `mode` is `popup` or `panel` |
| `getConnection()` / `setConnection(json)` / `clearConnection()` | `chrome.storage.local['connection']` (merge-write) |
| `requestOrigins(json)` / `hasOrigins(json)` | `chrome.permissions`; request only inside a user gesture |
| `requestSiteAccess(origin)` | per-site access for the browser tools |
| `toolGroups()` / `onToolGroupsChanged(cb)` | JSON tool groups: `browser` plus the current `webmcp` group |
| `callTool(group, id, argsJson)` | resolves to `{ok,result}` or `{ok:false,error}`; never rejects; redacted, bounded, 50 s timeout |
| `setVisible(bool)` | starts/stops the WebMCP watcher |
| `openSidePanel()` | popup only; `false` if unsupported |

## Build

```powershell
scripts/build_extension.ps1                 # production: server https://api.subconscious.chat
scripts/build_extension.ps1 -Dev            # engine dev port 51515, server http://127.0.0.1:5050/
scripts/build_extension.ps1 -ServerUrl https://other.example
scripts/build_extension.ps1 -Dev -SkipBuild # reuse apps/unified_app/build/web
```

It runs `flutter build web --release --no-web-resources-cdn --csp --no-source-maps --base-href / --dart-define=SUBCONSCIOUS_EXTENSION=true ...`,
copies the result to `app/`, strips the service worker and unused renderers (skwasm needs cross-origin isolation, so CanvasKit is used),
generates `popup.html` / `sidepanel.html`, and verifies no inline scripts and lists remaining remote URLs and `eval(` use.
Rebuild after every Dart change, then click reload on `chrome://extensions`.

## Load locally

1. Run the build script.
2. `chrome://extensions` -> Developer mode -> Load unpacked -> this folder (Chrome 116+). The VS Code configs
   "Chromium Extension (Chrome/Edge)" run the build (`-Dev`) first.
3. Chrome for Testing / Chromium also work: `--load-extension=<this folder>`. Branded Chrome 137+ ignores `--load-extension`;
   use Chrome for Testing or the Developer-mode button.

## Troubleshooting

- Blank page: open the popup's DevTools (right-click -> Inspect). `Refused to execute ... Content Security Policy` means a script needs `eval`;
  rebuild (the script uses `--csp`).
- `app/` missing: run the build script; `app/` is git-ignored.
- Browser tools say "Grant access to <origin>": grant site access from the app (needs a click).
- Tool/redaction tests: `node --test tools/redact.test.mjs`.
